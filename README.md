## Описание

Приложение создано на Android с использованием Jetpack Compose и Material3.

На экране расположено многострочное текстовое поле для ввода заметки, кнопка "Сохранить" и кнопка "Очистить".

При нажатии на кнопку "Сохранить" введённый текст отображается ниже в карточке с закруглёнными краями. При повторном сохранении старая заметка заменяется новой. Кнопка "Очистить" удаляет текст из поля ввода и очищает карточку.

## Использованные элементы

- OutlinedTextField
- Button
- OutlinedButton
- Card
- remember
- mutableStateOf
- Material3
